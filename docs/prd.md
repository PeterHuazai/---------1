# 需求文档

## 1. 应用概述

### 1.1 应用名称

大学生学习与生活综合管理平台

### 1.2 应用描述

面向全国高校本科生、研究生的一站式学习与生活综合管理Web平台，集成课程管理、任务提醒、资料整理、学习计划打卡、校园生活服务功能，解决课程杂乱、作业考试易遗漏、学习资料分散、日常学习生活无规划、校园信息分散的核心痛点，提升学习效率，规整大学生活节奏，提供便捷的校园生活服务。

### 1.3 核心价值

- 课程信息集中管理，自动生成课表并提供上课提醒
- 作业考试任务分类管理，多级邮箱提醒防止遗漏
- 学习资料分类存储，快速检索与在线预览
- 学习目标打卡与数据统计，养成持续学习习惯
- Python后端微服务提供邮件发送、学习统计报告生成、课程冲突检测、智能学习建议功能
- 校园生活服务：空教室查询、社团活动通知、二手交易、失物招领、校园资讯
- 管理员后台系统：用户管理、内容管理、数据统计

### 1.4 设计风格

- 整体风格：极简清爽、年轻化、现代化
- 主色调：蓝色（#165DFF）
- 辅助色：白色（#FFFFFF）、浅灰色（#F5F7FA、#E5E6EB）
- 强调色：橙色（#FF7D00）用于紧急提醒
- 字体：Inter、思源黑体无衬线字体
- 图标：简约线性图标
- 布局：模块化卡片式布局，功能分区清晰
- 管理员后台：侧边栏导航+数据表格为主，简洁实用

## 2. 用户与使用场景

### 2.1 目标用户

全国各高校全日制本科生、研究生

### 2.2 用户特征

- 日常多任务并行，时间碎片化
- 对数字化工具接受度高
- 追求极简操作、无冗余流程
- 主要通过电脑网页端使用平台

### 2.3 核心使用场景

- 学期初录入课程信息，生成课表并设置上课提醒
- 日常添加作业、考试任务，接收邮箱提醒
- 上传整理各科学习资料，快速检索查看
- 设置学习目标并打卡，查看学习数据统计
- 查看学习统计报告，获取智能学习建议
- 查询空教室，查看社团活动并报名
- 发布二手物品交易信息，浏览二手交易
- 发布失物招领信息，查看失物招领
- 浏览校园资讯
- 管理员管理用户、内容、数据统计

### 3.2 首页

#### 3.2.1 今日课程卡片

- 展示当天所有课程信息：课程名称、上课时间、授课地点
- 按时间顺序排列
- 点击课程可跳转至课程详情页

#### 3.2.2 待办任务卡片

- 展示未完成的作业、考试任务
- 按截止时间倒序排列，最多展示5条
- 根据紧急程度配色标注：红色（24小时内）、黄色（7天内）、灰色（7天以上）
- 点击任务可跳转至任务详情页

#### 3.2.3 近期考试卡片

- 展示未来7天内的考试安排
- 显示考试科目、考试时间、考试地点
- 点击可跳转至考试日历页

#### 3.2.4 重要通知卡片

- 展示系统通知、上课提醒、任务提醒等消息
- 最多展示3条最新通知
- 点击可跳转至消息中心

#### 3.2.5 卡片顺序调整

- 支持拖拽调整卡片展示顺序
- 调整后的顺序自动保存

### 3.3 课程表管理

#### 3.3.1 课表展示页

- 默认周视图展示当前周课程
- 支持切换日视图、月视图
- 不同课程自动匹配不同配色
- 显示课程名称、上课时间、授课地点
- 点击课程可查看课程详情
- 支持左右切换查看其他周/日/月的课程
- 提供「添加课程」入口
- 若检测到课程时间冲突，在课表中标注冲突提示

#### 3.3.2 课程录入页

- 手动录入课程信息：
  - 课程名称（必填）
  - 上课时间（必填，支持选择星期、节次、起止周）
  - 授课地点（必填）
  - 任课老师（选填）
  - 学分（选填）
  - 课程类型（选填，如必修/选修/通识）
- 支持设置上课提醒时间（课前15分钟/30分钟/1小时）
- 提供「保存」「取消」按钮

#### 3.3.3 课程详情页

- 展示课程完整信息
- 提供「编辑」「删除」「添加备注」功能
- 显示该课程关联的作业、考试任务
- 显示调课记录

#### 3.3.4 课程导入导出页

- 支持上传Excel/CSV格式课程数据批量导入
- 提供课程数据模板下载
- 支持将当前课表导出为Excel/CSV格式
- 导入时调用Python后端接口自动检测课程时间冲突，提示用户确认

#### 3.3.5 课表分享

- 生成课表图片或链接
- 支持复制链接分享

#### 3.3.6 提醒机制

- 根据用户设置的提醒时间，在上课前发送提醒
- 提醒方式：站内通知+绑定邮箱邮件提醒
- 站内通知显示在消息中心
- 邮件提醒通过Python后端微服务发送至用户绑定邮箱（使用163邮箱SMTP）

### 3.4 作业与考试提醒

#### 3.4.1 任务列表页

- 展示所有待办任务，按截止时间倒序排列
- 根据紧急程度配色标注：红色（24小时内）、黄色（7天内）、灰色（7天以上）
- 显示任务名称、对应课程、截止时间、任务状态
- 支持筛选：按课程、任务类型（作业/考试/实验报告等）、任务状态筛选
- 支持搜索：按任务名称搜索
- 提供「添加任务」入口
- 点击任务可查看任务详情

#### 3.4.2 任务录入页

- 选择对应课程（必填）
- 选择任务类型（必填，如作业/实验报告/课程论文/期末考试/随堂测验）
- 填写任务名称（必填）
- 填写截止时间或考试时间（必填）
- 填写提交方式（选填）
- 填写成绩占比（选填）
- 填写任务备注（选填）
- 设置多级提醒节点（选填，如截止前3天/1天/1小时、考试前1天/3小时）
- 提供「保存」「取消」按钮

#### 3.4.3 任务详情页

- 展示任务完整信息
- 提供「编辑」「删除」功能
- 支持手动标记任务状态：未开始/进行中/已完成
- 已完成任务自动归档

#### 3.4.4 考试日历页

- 以日历形式展示学期所有考试安排
- 点击日期可查看当天考试详情
- 支持导出考试日历为图片或PDF格式

#### 3.4.5 历史任务查看

- 展示已完成和已归档的任务
- 支持按时间、课程筛选查看

#### 3.4.6 提醒机制

- 根据用户设置的提醒节点，在截止前或考试前发送提醒
- 提醒方式：站内通知+绑定邮箱邮件提醒
- 站内通知显示在消息中心
- 邮件提醒通过Python后端微服务发送至用户绑定邮箱（使用163邮箱SMTP）

### 3.5 学习资料管理

#### 3.5.1 资料列表页

- 展示所有上传的学习资料
- 支持按课程、章节、文件类型分类展示
- 显示文件名称、文件类型、上传时间、对应课程
- 支持搜索：按文件名、关键词、上传时间、对应课程筛选搜索
- 提供「上传资料」入口
- 点击资料可在线预览或下载

#### 3.5.2 资料上传页

- 支持本地文件上传
- 选择对应课程（必填）
- 选择章节（选填）
- 自动识别文件类型（PDF、代码文件、实验文档等）
- 提供「上传」「取消」按钮

### 3.6 学习打卡与计划

#### 3.6.1 目标设置页

- 支持自定义每日、每周、每月学习目标
- 目标类型包括：背单词、刷题、专业课复习、实验练习、早起、运动、阅读等
- 填写目标名称（必填）
- 选择目标周期（必填，如每日/每周/每月）
- 填写目标描述（选填）
- 提供「保存」「取消」按钮

#### 3.6.2 打卡记录页

- 展示所有设置的学习目标
- 显示目标名称、目标周期、连续打卡天数
- 提供「一键打卡」按钮
- 打卡时可附加学习笔记、心得记录
- 显示打卡日历，标记已打卡日期

#### 3.6.3 数据统计页

- 自动统计连续打卡天数
- 统计每日/每周学习时长
- 统计各科目学习时间占比
- 生成可视化统计图表（柱状图、饼图、折线图）
- 支持切换查看日度、周度、月度数据

#### 3.6.4 学习报告页

- 调用Python后端接口自动生成周度、月度学习统计报告
- 报告内容包括：学习时长、打卡次数、完成任务数、各科目学习占比
- 调用Python后端接口生成智能学习建议文本（根据打卡数据和任务完成情况）
- 支持在线查看
- 支持导出学习报告

## 4. 业务规则与逻辑

### 4.1 课程时间冲突检测

- 添加或导入课程时，调用Python后端接口自动检测课程时间是否冲突
- 若存在冲突，提示用户确认是否继续添加
- Python后端从Supabase数据库读取用户课程数据，检测时间重叠的课程

### 4.2 任务紧急程度自动标注

- 根据任务截止时间自动计算紧急程度
- 24小时内截止：红色标注
- 7天内截止：黄色标注
- 7天以上截止：灰色标注

### 4.3 提醒推送逻辑

- 上课提醒：根据用户设置的提醒时间，在上课前发送提醒
- 任务提醒：根据用户设置的提醒节点，在截止前或考试前发送提醒
- 提醒方式：站内通知+绑定邮箱邮件提醒
- 站内通知实时推送至消息中心
- 邮件提醒通过Python后端微服务发送至用户绑定邮箱（使用163邮箱SMTP）

### 4.4 任务状态自动更新

- 用户手动标记任务为「已完成」后，任务自动归档
- 已归档任务不再显示在任务列表页，可在历史任务中查看

### 4.5 数据统计自动计算

- 每日自动统计用户打卡情况、学习时长
- 每周、每月调用Python后端接口自动生成学习统计报告
- Python后端从Supabase数据库读取用户打卡记录、任务完成情况，统计打卡次数、完成任务数、学习时长

### 4.6 智能学习建议生成

- 调用Python后端接口根据用户打卡数据和任务完成情况生成智能学习建议文本
- Python后端从Supabase数据库读取用户数据，分析学习规律，生成建议文本

### 4.7 数据备份逻辑

- 用户可手动触发数据备份
- 系统每周自动备份用户数据至云端
- 备份数据包括：课程信息、任务信息、资料信息、打卡记录、个人设置

### 4.8 Python后端微服务架构

- Python后端接入Supabase数据库，读取用户数据
- Python后端提供以下接口：
  - 邮件发送接口（使用163邮箱SMTP）
  - 学习统计报告生成接口（周报/月报）
  - 课程冲突检测接口
  - 智能学习建议生成接口
- 前端调用Python后端接口实现相关功能
- Python代码包含详细中文注释

### 4.9 校园生活功能权限控制

- 浏览权限：无需登录即可浏览校园资讯、空教室查询、社团活动、二手交易、失物招领
- 发布权限：需登录后才能发布社团活动、二手交易、失物招领
- 报名权限：需登录后才能报名社团活动
- 标记权限：仅发布者可标记失物招领为「已找到」

### 4.10 管理员后台权限控制

- 管理员登录：验证管理员角色（role='admin'）
- 管理员权限：管理用户、内容、交易/失物、查看数据统计
- 普通用户无法访问管理员后台

### 4.11 失物招领状态更新

- 发布者可手动标记失物招领为「已找到」
- 标记后状态自动更新，失物列表页显示「已找到」标签

### 4.12 社团活动报名逻辑

- 用户点击「报名」按钮后，报名信息存储至后端
- 活动详情页显示已报名人数
- 报名截止时间后，「报名」按钮自动禁用

## 5. 异常与边界情况

| 场景               | 处理方式                                         |
| ------------------ | ------------------------------------------------ |
| 用户未绑定邮箱     | 提示用户绑定邮箱，否则无法接收邮件提醒           |
| 课程时间冲突       | 提示用户确认是否继续添加冲突课程                 |
| 任务截止时间已过   | 任务自动标记为「已过期」，提示用户处理           |
| 文件上传失败       | 提示用户检查网络或文件格式，支持重新上传         |
| 文件格式不支持预览 | 提示用户下载后查看                               |
| 数据备份失败       | 提示用户检查网络，支持重新备份                   |
| 用户删除课程       | 提示用户确认删除，删除后关联的任务、资料不受影响 |
| 用户删除任务       | 提示用户确认删除，删除后无法恢复                 |
| 用户删除资料       | 提示用户确认删除，删除后无法恢复                 |
| 用户修改邮箱       | 发送验证邮件至新邮箱，验证通过后完成修改         |
| 用户忘记密码       | 通过绑定邮箱发送重置密码链接                     |
| 页面加载超时       | 提示用户检查网络，支持刷新重试                   |
| Python后端接口调用失败 | 提示用户检查网络，支持重试                   |
| 邮件发送失败       | 提示用户检查邮箱配置，支持重新发送               |
| 学习报告生成失败   | 提示用户检查数据完整性，支持重新生成             |
| 未登录用户发布内容 | 提示用户登录后才能发布                           |
| 未登录用户报名活动 | 提示用户登录后才能报名                           |
| 非管理员访问后台   | 提示无权限访问，跳转至登录页                     |
| 管理员删除违规内容 | 提示确认删除，删除后无法恢复                     |
| 空教室查询无结果   | 提示当前时段无空闲教室                           |
| 社团活动报名截止   | 「报名」按钮自动禁用，提示报名已截止             |
| 失物招领已找到     | 显示「已找到」标签，禁止再次标记                 |
